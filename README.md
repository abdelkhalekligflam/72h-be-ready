# 72H Be Ready

Premium bilingual EN/FR digital study guide storefront built with Next.js, TypeScript and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

## Implemented
- Responsive premium dark landing page
- English / French language toggle
- Guide presentation and FAQ

## Next steps
